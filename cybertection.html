Cybertection — Secure VPN Management System

A security-focused internship project combining application development, authentication, VPN configuration, and administrative monitoring.

PythonFlaskFirebaseFirestoreWireGuardREST APIsPyQt5Linux

Project overview

During my Cybertection internship, I worked on a VPN management application that brought together Python backend development, user authentication, cloud data storage, and VPN administration. The project focused on simplifying user and connection management through application interfaces while applying secure-access principles.

My work involved developing and testing application components, integrating services, and troubleshooting the flow of information between the backend, the database, and the desktop interface.

Project highlights

  • Backend and API development: Worked with a Python Flask backend and REST API endpoints supporting account and VPN management workflows.
  • Authentication and data: Integrated Firebase Authentication and Firestore to handle user-related records and connection/session information.
  • VPN configuration: Worked with WireGuard configurations and peer-management functionality as part of the secure connection workflow.
  • Desktop interface: Built or updated PyQt5 interface components for user and administrative views of VPN session information.
  • Testing and debugging: Tested authentication and endpoint behavior, inspected data returned to the interface, and investigated session-state and connection-management issues.

How the components fit together

The application used a desktop interface to interact with backend services. The backend handled requests related to user accounts and VPN management, while Firebase services supported authentication and stored application records. WireGuard provided the VPN technology used in the project.

What I learned

This project strengthened my experience connecting multiple technologies into a security-focused application. It gave me hands-on practice with backend APIs, authentication, database integration, VPN configuration concepts, and debugging across application layers. I also learned how important it is to verify session behavior and secure access controls rather than assuming a feature works just because its interface is present.
